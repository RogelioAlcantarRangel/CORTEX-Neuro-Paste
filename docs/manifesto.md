# CORTEX Manifesto

## The Falling Edge Law

Every interaction must return **visible feedback in under 16ms**. When the system responds instantly, the user stays in flow and the tool feels like an extension of their nervous system.

## Speculative Execution

**Action → Show → Refine** is the core loop:

1. **Action:** Execute the user’s intent immediately.
2. **Show:** Provide instant feedback so the user never waits.
3. **Refine:** Improve the output asynchronously without breaking the flow.

## Neuro-Paste Principles

- **Latency is the enemy of cognition.** Every extra millisecond increases context switching.
- **Feedback is non-negotiable.** UI updates must happen before computation is complete.
- **Safety first.** Any automated refinement must be reversible and cancelable.

## What This Enables

By treating time-to-feedback as a primary design constraint, CORTEX turns routine actions (like pasting) into a seamless cognitive extension rather than a friction point.
