# Reports de benchmark por release

Este directorio versiona evidencia de performance y estabilidad por release.

## Estructura
- `reports/<version>/benchmark.md`: resumen ejecutivo de métricas clave.
- `reports/<version>/raw/`: datos crudos (CSV/JSON) usados para calcular métricas.

## Métricas mínimas por release
- WS error rate.
- Latencia p95 (ms).
- Estabilidad ante cambio de foco.
- Cobertura de apps objetivo (Notepad/Office/IDE).
